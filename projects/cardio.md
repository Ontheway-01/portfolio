# 스마트폰 음향 신호처리 및 모바일 센싱

[← 포트폴리오](../README.md) · [모바일 구현 상세](cardio-implementation.md) · [연구 이력](research.md)

**단일 마이크 음향 신호의 잡음 억제를 위한 필터를 설계·튜닝하고 실시간 모바일 앱에 적용했습니다.** MATLAB 기반 분석, 3D 프린팅 액세서리 제작, 모바일·웨어러블 연동을 담당했습니다.

`Single-microphone sensing` `MATLAB` `FFT` `Filtering` `Kotlin` `Wear OS` `Physical prototyping`

## 문제와 본인 역할

스마트폰 음향 센싱에서는 작은 목표 신호와 주변 소음, 기기의 접촉·이동 상태를 함께 다뤄야 합니다. 신호를 수집하는 물리적 구조, 필터 처리, 앱의 녹음·재생을 연결하는 프로젝트 전반에 참여했습니다.

단일 마이크 신호처리를 중심으로 필터 설계와 파라미터 튜닝, 처리 전후 신호 분석, 실시간 앱 적용을 수행했습니다. 듀얼 마이크 입력과 모바일·워치 연동도 구현 경험에 포함됩니다.

## MATLAB 기반 신호 분석과 필터 구현

시간 영역 파형과 FFT 기반 주파수 분석으로 수집 신호를 살펴보고, band-pass filtering과 잡음 억제 처리를 구현했습니다. 분석 구간, 필터 파라미터와 출력 신호를 바꾸어가며 원본과 처리 결과를 비교했습니다.

분석 환경에서는 필터 계산과 시각화·오디오 파일 출력을 연결했습니다. 필터 함수와 입력·출력 단계를 나누어, 오프라인 분석에서 확인한 처리를 모바일 구현으로 옮기는 작업을 수행했습니다.

## 실시간 모바일 앱 적용

오디오 수집·처리·재생 경로를 구성하고, 처리 전 원본을 별도로 기록했습니다. 신호처리 루프와 사용자 제어·기기 상태 처리를 구분해 구현했습니다.

반복 처리에 필요한 배열을 재사용하고, IMU 기반 상태 판정과 오디오 출력 정책을 연결했습니다. 신호 분석 결과를 앱의 실제 입력·출력 조건에 맞게 구현한 경험입니다.

## 물리적 프로토타입과 웨어러블 연동

Fusion으로 수집 액세서리를 모델링하고 Bambu Lab 장비로 출력·조립했습니다. 스마트폰 기종에 맞춘 가이드와 접촉 구조를 제작해 소프트웨어 입력과 물리적 수집 환경을 함께 다뤘습니다.

모바일 오디오 처리 결과를 워치 피드백과 연결했습니다. 기록 경로와 실시간 피드백 경로의 목적을 나누고, 전송 대기와 재생 상태를 관리했습니다.

## 구현 산출물

- 모바일 오디오 수집·처리·기록·재생 경로
- IMU 기반 기기 상태와 출력 정책 연동
- 3D 모델·출력 액세서리 및 워치 피드백 프로토타입
