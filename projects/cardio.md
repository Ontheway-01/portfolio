# 스마트폰 기반 심음 신호 분석과 모바일 시스템 개발

[← 포트폴리오](../README.md) · [시스템 개발 경험](cardio-implementation.md) · [연구 이력](research.md)

**심음 데이터를 분석하고, 이를 수집·처리하는 모바일 시스템과 센싱 프로토타입을 개발했습니다.** MATLAB 기반 신호 분석부터 앱 구현과 실물 제작까지 연구 과정 전반에 참여했습니다.

`Signal processing` `MATLAB` `Mobile development` `Physical prototyping`

## 담당 역할

- **신호 분석:** MATLAB으로 심음 데이터의 파형과 주파수 특성을 살펴보고 신호처리 작업을 수행했습니다.
- **모바일 개발:** 데이터 수집·기록과 처리 결과 확인을 위한 앱 기능을 구현했습니다.
- **프로토타입 제작:** Fusion 모델링과 Bambu Lab 출력을 활용해 센싱 액세서리를 제작했습니다.
- **시스템 연동:** 모바일·웨어러블 기기 사이의 데이터 전달과 사용자 피드백 기능을 구현했습니다.

## 연구를 통해 쌓은 경험

분석 코드, 모바일 소프트웨어, 물리적 수집 환경을 함께 다뤘습니다. 각 요소를 개별적으로 구현하는 데서 나아가 실제 기기에서 수집·처리·확인이 이어지도록 연결하는 경험을 쌓았습니다.
