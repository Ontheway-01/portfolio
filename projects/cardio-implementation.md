# 심음 센싱을 위한 모바일·웨어러블 시스템 개발

[← 연구 경험](cardio.md) · [포트폴리오](../README.md)

**심음 데이터 분석을 위한 수집 환경과 모바일·웨어러블 앱 기능을 구현했습니다.** 신호 분석, 앱 개발, 실물 제작을 연결하는 역할을 담당했습니다.

`MATLAB` `Kotlin` `Android / Wear OS` `Fusion` `Bambu Lab`

## 데이터 분석과 앱 구현

MATLAB을 활용해 수집 데이터를 분석하고 신호처리를 수행했습니다. 모바일 앱에서는 데이터 수집·저장과 결과 확인을 위한 기능을 구현했습니다.

## 모바일·웨어러블 연동

모바일 기기와 워치 사이의 데이터 전달 및 피드백 기능을 개발했습니다. 기기 연결과 앱 상태를 고려해 수집과 사용자 조작이 이어지도록 구성했습니다.

## 센싱 프로토타입 제작

Fusion으로 액세서리를 모델링하고 Bambu Lab 장비로 출력·조립했습니다. 물리적 수집 환경과 앱의 사용 흐름을 함께 고려하며 프로토타입을 제작했습니다.
